# Métodos comuns para Todos os Objetos

# Resumo do capítulo 3

A classe `Object` foi projetada para extensão, como todos nós sabemos o Java permite poliformismo,
em outras palavras, todos os objetos herdam de `Object`.

Os métodos `toString`, `hashCode`, `clone` e o `finalize` foram projetados para serem sobrescritos.
Cada classe é responsável por sobrescrever esses métodos a fim de obedecer a seus contratos gerais.
Caso não o faça, impedirá que outras classes que dependem desses contratos (`HashMap`, `HashSet`),
não funcionem de modo adequado.
